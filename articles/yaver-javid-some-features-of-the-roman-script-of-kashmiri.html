Some Features Of The Roman Script Of Kashmiri
Author : Yaver Javid

Kashmiri on social media has been written in the Roman Script for years now. Here are some of it's features :

The phenome ts is seen written via cx, ts, c, xc & ch. ts is seen in academic papers and cx is used in more refined writing. And it's aspirated variant is seen written by c, ch, cxh & tsh.

The vowel ɔ is typically written using ou and oa. The vowel system is pretty inconsistant to create a proper map.
